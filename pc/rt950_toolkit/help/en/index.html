1. Getting started

BricoHams RT-950 Toolkit programs the Radtel RT-950 and RT-950 Pro over the programming cable, on Windows and Linux. It works with radios running the stock Radtel firmware and with the BricoHams custom firmware.

SystemInstallation
Windows 10/11Run BricoHams-RT950-Toolkit-Setup-x.y.z.exe. The installer is signed by BricoHams; if Windows warns about an unknown publisher, see Troubleshooting.
Debian / Ubuntusudo apt install ./bricohams-rt950-toolkit_x.y.z_all.deb
Arch Linuxsudo pacman -U bricohams-rt950-toolkit-x.y.z-1-any.pkg.tar.zst
Other distributionsPortable executable RT950Toolkit-linux-x64 (chmod +x) or from source: python3 pc/run_toolkit.py

On Linux the user needs access to the serial port: sudo usermod -aG dialout $USER (Debian/Ubuntu) or uucp (Arch), then log in again. The .deb and Arch packages add a udev rule for the cable.

Plug in the cable, switch the radio on and choose the Port (Refresh searches again): COMx on Windows, /dev/ttyUSB0 or /dev/ttyACM0 on Linux.

On first start the disclaimer is shown; it must be accepted to work with the radio from the program.

2. Read and save

Read from radio detects the firmware (stock or custom) and reads the whole configuration. When it finishes it saves a dated backup (Radio → Open backups folder). Save your work with File → Save (.rt950 format).

4. Country codeplugs

Tools → Country codeplug… loads a ready-to-use configuration:

CountryZones 1–9Zone 10
SpainEA1 … EA9: 2 m and 70 cm FM repeaters of the call district (URE list) and the frequencies of the airports in the district (tower, approach, ATIS, ground, information; RX only, AM).PMR-CB: PMR446 (16 channels) and CB-27 (40 channels), RX only.
United KingdomOne zone per ETCC region (SE, SW and Channel Islands, Midlands, East Anglia, North and Isle of Man, Wales, Scotland, Northern Ireland) with FM repeaters (ukrepeater.net) and airports; zone 9: simplex, APRS and ISS.PMR-CB: PMR446, UK CB 27/81 and CEPT CB, RX only.

Overwrite replaces all channels (new radio, or to start afresh). Add keeps your channels: the country channels go into the free slots of each zone and the ones you already have are skipped. With Rename the zones unticked only unnamed zones are renamed.

A zone holds 99 channels. When they do not all fit, the ones closest to My locator (or to the middle of the zone) are kept. Preview shows how many are added to each zone and which do not fit.

Already configured radio: first Read from radio, then Country codeplug → Add, check, and Write to radio. A country codeplug made from scratch only writes channels and zone names: the radio settings are not touched.

Ready-made codeplugs are also published with every release (codeplug-ES.rt950, codeplug-GB.rt950 and their CSV files for CHIRP and RT-950 Editor).

The data comes from public lists and can change: check the repeaters in your area. Air band, PMR446 and CB channels are loaded with transmit disabled.

5. Write to the radio

Write to radio first reads the radio and saves a backup (before-write), writes, then reads every block back to verify it. Radio → Write channels only writes channels and zones. Only the bytes of edited fields are changed; anything unknown is preserved.

6. Firmware

The Firmware tab updates the radio over the cable through the maker's bootloader:

  1. Check online lists the firmware published with the project releases (their SHA-256 is checked), or From file… for your own .BTF, for example Radtel's official one.
  2. Choose the port and press Flash firmware. The radio restarts into the bootloader, receives the firmware and boots again.
  3. If the radio does not answer or does not boot, switch it off, hold the two lower side keys while switching it on, and tick Radio already in bootloader mode.

You can also flash from the browser (Chrome or Edge) with the web flasher.

The installed firmware cannot be read from the radio. Before changing it, keep the original .BTF (see Backups). To go back to Radtel's firmware, flash its official .BTF.

7. Satellites

Satellites tab: enter your locator, Update TLE and Calculate passes. With the stock firmware, Add creates split Doppler channels (AOS, A2, TCA, L2, LOS) and the report says when to change channel. With the custom firmware, Upload to radio loads TLEs, frequencies and passes, and the radio corrects the Doppler shift in real time (Satellite menu or long press of D).

8. APRS

The APRS tab configures the beacon. The custom firmware adds text messaging with acknowledgements: radio menu APRS Set → Messages (inbox, multi-tap compose, quick texts on B).

10. Command line

RT950Toolkit read  --port COM5 -o radio.rt950
RT950Toolkit write --port COM5 radio.rt950 [--channels-only]
RT950Toolkit country GB -o uk.rt950 [--locator IO91WM]
RT950Toolkit country GB -i radio.rt950 --mode append -o radio+uk.rt950
RT950Toolkit flash --port COM5 firmware.BTF [--in-bootloader]
RT950Toolkit sat all --locator IO91WM [--port COM5]

11. Troubleshooting

ProblemSolution
Windows SmartScreen: "Windows protected your PC"Click More info → Run anyway. The installer is signed with the BricoHams certificate; for Windows to recognise the publisher, install BricoHams-CodeSigning.cer (included in the release) into "Trusted People" and "Trusted Publishers". Check the SHA256SUMS file too.
"The radio did not answer"Cable fully inserted in the radio, radio on, right port, and no other program using the port.
Linux: permission denied on /dev/ttyUSB0Add your user to the dialout group (uucp on Arch) and log in again.
"Verify failed in …"Write again. If it repeats, restore the last backup (Radio → Restore a backup).
Interrupted flashingBootloader mode (two lower side keys at power on) and flash again with "already in bootloader mode" ticked.

12. Backups

Configuration (codeplug)

  • Every read and every write saves a dated backup in the backups folder.
  • Also keep your own copy with File → Save and, if you use the official software, as a .dat.
  • To go back: Radio → Restore a backup.
  • Copy the backups folder to a USB stick or the cloud now and then.

Firmware

  • The firmware cannot be read from the radio: the backup is the original .BTF file.
  • Before installing the custom firmware, note your radio's version and keep the official .BTF of that version (Radtel's web site, or the repository's binary/ folder for V0.15–V0.27).
  • To go back to the original: Firmware tab → From file → official .BTF → Flash.

Calibration

Factory calibration lives in the radio's memory; neither this program nor the custom firmware changes it. Do not erase the whole memory with other tools.

Before every operation

Battery above 50 %, cable firmly connected, and do not disconnect while writing or flashing.
